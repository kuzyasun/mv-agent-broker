How profile names and native subagents work

A profile saves a provider, model, effort, role and permissions. Its name is editable: *_worker is our preset for one worker, cursor_large / agy_large encourage subagents for larger tasks, and *_reviewer is for independent review. The fields below determine behavior.

Off requests one agent. Prefer subagents suggests a maximum. Agent decides lets the agent choose whether and how many to use. These are prompt instructions; the broker cannot enforce child count. ZCode can handle large tasks, but its native subagents are unverified, so there is no zcode_large preset. Duplicate a profile to add a preset.
